一个候选状态是怎样生成的？

BoardState.legal_moves() 先筛合法移动，apply() 再得到新棋盘。

1

只拿外端连续同类鸟

ACBB ⇢ BB

从元组末尾数，连续段长度记为 run。

2

目标必须空着或同色

B → AB ✓

目标已满、已消除或外端颜色不同，都跳过。

3

一次尽量多搬

count = min(run, 剩余空位)

这与游戏里点一次后自动搬运的行为一致。

4

四只同类，整枝消失

AAAA → ✓

用 REMOVED = (-1,) 标记，之后不能再接鸟。

三种“其实没必要搜”的情况

剪掉对称或原地踏步的分支，把束宽留给真正不同的未来。

[A][B][ ]≡[ ][B][A]

树枝位置对称

对所有树枝排序后做键；只是交换位置的棋盘只搜一次。

[ ][ ]→[A]第二个空枝

多个空枝等价

同一组鸟移到哪根空枝都一样，只考虑第一根空枝。

[AAAA]→[ ]搬家

同色整枝搬空枝

这只是在交换“同色枝”和“空枝”的位置，不产生进展。
